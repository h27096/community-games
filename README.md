# Community Games 🎮

A website where the community plays simple shared games together.

## Games

- 🫘 **Beans** — send one or many bean emojis in a message. Every `🫘` counts toward the shared community goal, and the message is shown in the feed.
- 🔢 **Community Counting** — the community submits the next number. Each person gets one successful submission every 60 seconds.
- 😀 **Emoji Challenge** — the community works through one shared emoji sequence. Each person gets one successful submission every 60 seconds.

## Username system

The first time someone opens the site, they choose a username. For this first version the username is saved in that browser with `localStorage`. It is displayed on community messages, but it is not a secure account/login system yet.

## Shared data

GitHub Pages hosts the frontend. A shared Supabase project stores the community state, messages, and server-side cooldowns. This prevents each visitor from having their own separate Beans/counting progress.

### Supabase setup

1. Create a Supabase project.
2. Open **SQL Editor**.
3. Run the SQL below.
4. In `script.js`, replace `YOUR_SUPABASE_URL` and `YOUR_SUPABASE_ANON_KEY` with the project's public URL and anon/publishable key. Never put a Supabase service-role key in this website.
5. Enable Realtime for `challenge_state` and `challenge_messages` if your Supabase project does not already have it enabled.

```sql
create table if not exists public.challenge_state (
  id integer primary key check (id = 1),
  beans_total bigint not null default 0,
  beans_goal bigint not null default 20000,
  counting_number bigint not null default 0,
  emoji_index integer not null default 0,
  emoji_sequence jsonb not null default '["😀","😃","😄","😁","😆","😅","😂","🤣","😊","😇","🙂","🙃","😉","😌","😍","🥰","😘","😗","😙","😚","😋","😛","😝","😜","🤪","🤨","🧐","🤓","😎","🤩","🥳"]'::jsonb
);

insert into public.challenge_state (id)
values (1)
on conflict (id) do nothing;

create table if not exists public.challenge_messages (
  id bigint generated by default as identity primary key,
  challenge text not null check (challenge in ('beans','counting','emoji')),
  username text not null check (char_length(username) between 2 and 24),
  content text not null check (char_length(content) between 1 and 500),
  amount integer,
  challenge_value bigint,
  created_at timestamptz not null default now()
);

create index if not exists challenge_messages_created_idx on public.challenge_messages (created_at desc);
create index if not exists challenge_messages_challenge_idx on public.challenge_messages (challenge, created_at desc);

create table if not exists public.challenge_cooldowns (
  username text not null,
  challenge text not null check (challenge in ('counting','emoji')),
  next_allowed_at timestamptz not null,
  primary key (username, challenge)
);

-- Public reads are allowed so visitors can see the same community state/feed.
alter table public.challenge_state enable row level security;
alter table public.challenge_messages enable row level security;
alter table public.challenge_cooldowns enable row level security;

drop policy if exists "public read challenge state" on public.challenge_state;
create policy "public read challenge state" on public.challenge_state for select using (true);

drop policy if exists "public read challenge messages" on public.challenge_messages;
create policy "public read challenge messages" on public.challenge_messages for select using (true);

-- Writes are performed by the RPC functions below, not direct table writes.
revoke insert, update, delete on public.challenge_state from anon, authenticated;
revoke insert, update, delete on public.challenge_messages from anon, authenticated;
revoke select, insert, update, delete on public.challenge_cooldowns from anon, authenticated;

grant select on public.challenge_state to anon, authenticated;
grant select on public.challenge_messages to anon, authenticated;
grant execute on function public.add_beans(integer,text,text) to anon, authenticated;
grant execute on function public.submit_count(bigint,text) to anon, authenticated;
grant execute on function public.submit_emoji(text,text) to anon, authenticated;

create or replace function public.add_beans(bean_amount integer, sender_username text, message_content text)
returns void
language plpgsql
security definer
set search_path = public
as $$
declare
  counted integer;
  new_total bigint;
begin
  if bean_amount < 1 or bean_amount > 500 then raise exception 'Invalid bean amount'; end if;
  if char_length(sender_username) < 2 or char_length(sender_username) > 24 then raise exception 'Invalid username'; end if;
  if char_length(message_content) < 1 or char_length(message_content) > 500 then raise exception 'Invalid message'; end if;
  counted := length(message_content) - length(replace(message_content, '🫘', ''));
  if counted <> bean_amount then raise exception 'Bean count mismatch'; end if;
  update challenge_state set beans_total = beans_total + bean_amount where id = 1 returning beans_total into new_total;
  insert into challenge_messages (challenge, username, content, amount, challenge_value)
  values ('beans', sender_username, message_content, bean_amount, new_total);
end;
$$;

create or replace function public.submit_count(submitted_number bigint, sender_username text)
returns void
language plpgsql
security definer
set search_path = public
as $$
declare
  current_value bigint;
  next_time timestamptz;
begin
  select next_allowed_at into next_time from challenge_cooldowns where username = sender_username and challenge = 'counting';
  if next_time is not null and next_time > now() then raise exception 'Cooldown active'; end if;
  select counting_number into current_value from challenge_state where id = 1 for update;
  if submitted_number <> current_value + 1 then raise exception 'Wrong number'; end if;
  update challenge_state set counting_number = submitted_number where id = 1;
  insert into challenge_messages (challenge, username, content, challenge_value)
  values ('counting', sender_username, submitted_number::text, submitted_number);
  insert into challenge_cooldowns (username, challenge, next_allowed_at)
  values (sender_username, 'counting', now() + interval '60 seconds')
  on conflict (username, challenge) do update set next_allowed_at = excluded.next_allowed_at;
end;
$$;

create or replace function public.submit_emoji(submitted_emoji text, sender_username text)
returns void
language plpgsql
security definer
set search_path = public
as $$
declare
  current_index integer;
  expected_emoji text;
  next_time timestamptz;
begin
  select next_allowed_at into next_time from challenge_cooldowns where username = sender_username and challenge = 'emoji';
  if next_time is not null and next_time > now() then raise exception 'Cooldown active'; end if;
  select emoji_index, emoji_sequence->>emoji_index into current_index, expected_emoji from challenge_state where id = 1 for update;
  if submitted_emoji <> expected_emoji then raise exception 'Wrong emoji'; end if;
  update challenge_state set emoji_index = current_index + 1 where id = 1;
  insert into challenge_messages (challenge, username, content, challenge_value)
  values ('emoji', sender_username, submitted_emoji, current_index + 1);
  insert into challenge_cooldowns (username, challenge, next_allowed_at)
  values (sender_username, 'emoji', now() + interval '60 seconds')
  on conflict (username, challenge) do update set next_allowed_at = excluded.next_allowed_at;
end;
$$;
```

### Emoji sequence

The challenge stores its sequence centrally so every visitor is on the same emoji. The starter sequence above is intentionally short for testing. Before launch, replace `emoji_sequence` with the complete intended Unicode RGI emoji sequence used by the project. The Apple keyboard is a platform rendering of Unicode emoji, so the site should use a defined Unicode sequence rather than depending on which device a visitor owns.

## Future roadmap

The database is intentionally separated into challenge state, messages, and cooldowns so future features can be added without rebuilding the site:

- 👍 message likes/reactions
- 👤 avatars and profiles
- 💳 credits earned from community goals
- 🛍️ shop with avatar clothing/items
- 🎯 more community goals and rewards
- 💬 direct messages with real accounts and privacy controls
